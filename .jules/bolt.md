## 2024-05-24 - Optimization: Extract instance method and avoid list creation overhead in tight loops
**Learning:** In performance-critical Python hot loops (like Monte Carlo evaluations in `compute_range_vs_range_equity`), avoiding the creation of intermediate lists dynamically with the `list()` constructor, as well as extracting instance methods (like `self.evaluator.evaluate`) out of the loop into a local variable can provide measurable performance improvements by reducing constructor and attribute lookup overhead. Combined with replacing dynamic `random.sample` filtering with a `while random.choice` approach using a pre-allocated boolean `forbidden` array (an existing pattern that was partially incomplete in this file), these micro-optimizations stack up nicely.
**Action:** Always check if inside tight loops we're needlessly constructing types via functions like `list()` instead of using list literal expansions (e.g. `[a, b] + my_list`). Similarly, extract object method lookups out of loops into local variables.
