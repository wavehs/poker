## 2025-03-02 - [Monte Carlo boolean array optimization fix]
**Learning:** In performance-critical Monte Carlo inner loops (such as `compute_range_vs_range_equity`), pre-allocating an O(1) `forbidden` boolean array (e.g., `[False] * 52`) outside the loop to track used cards is significantly faster than performing repeated list/tuple `in` checks or dynamically constructing sets on each iteration.
However, attempting to assign a boolean array directly to a `set` variable (e.g. `forbidden = set(v_hand) | set(sampled_board)`) causes a TypeError (`'set' object does not support item assignment`) because the `set` object cannot be accessed with array indices like `forbidden[v0]`.
**Action:** When using pre-allocated boolean arrays for tracking state, avoid inadvertently re-assigning the array variable to a Python `set` or other structure inside the loop. Instead, explicitly assign values to the array indices.
